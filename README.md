# The Good Samaritan: Mania Protocol Game Design Document

## Game Concept

Blend in. Be polite. Bury the evidence. A sandbox where being friendly keeps you alive. Maintain appearances, manage suspicion, and follow the steps - even when you don’t remember writing them. In a world built on small talk and secrets, how long can you keep the mask of a Good Samaritan?

### Introduction
The Good Samaritan: Mania Protocol is a first-person sandbox simulation horror game for PC. The player takes on the role of a serial killer receiving cryptic notes that guide them to their next victim.
